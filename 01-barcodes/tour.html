A model of memory

Wander, cache,
recall.

Three steps a chickadee's hippocampus takes to remember a hidden seed. The bubble above its head is the activity in that brain region.

This is a simplified model based on the public repository for the Fang et al. 2026 paper, "Barcode activity in a recurrent network model of the hippocampus enables efficient memory binding".
